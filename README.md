# Crepuscular

A Project Zomboid (Build 42) mod: day and night, with special moons and suns. Each can make zombies faster or slower, more fragile or tougher, make killed zombies get back up, tint the sky and set the fog, change sandbox options, and switch monster mods such as The Mutants and Cry of Fear on and off. Everything is set in sandbox options, so it works on any server, single player included.

**In testing:** expect bugs, and settings may still change between updates.

- [Builder](https://zexyqag.github.io/Crepuscular/builder/): write Day, Night and events in the browser.
